      Rule library

      One-click presets for common desktop-app deep links. Tweak the text pattern after adding if the page doesn't match.

      How matching works

      Domain pattern
      Matches against hostname or hostname + pathname. Use * as a wildcard. Examples: *.slack.com/archives/*, zoom.us/j/*, meet.google.com/*.
      Text pattern
      Text that must appear on the page before Oscar closes the tab. Leave blank to match any page on the domain (use with care). Substring mode is case-insensitive.
      Delay
      How long to wait after a match before closing the tab. This gives the page's deep-link handler time to fire the slack://, zoommtg://, etc. protocol.
      Oscar is local-only. No accounts, no telemetry, no servers.
